# 🏋️ ซ้อมกอล์ฟ

แอปแยกจาก Golf Live: ใช้มือถือช่วยซ้อมให้วงสวิงคงที่ และหาระยะกับจุดตั้งที่พอดีของแต่ละไม้

**เปิดแอป:** https://totsapark.github.io/golf-score/practice/ (กด "เพิ่มไปยังหน้าจอโฮม" เพื่อใช้เหมือนแอป)

ข้อมูลทั้งหมด (รอบที่บันทึก ผลซ้อม คลิปวงสวิง) อยู่ในมือถือเครื่องนั้นเท่านั้น ไม่ต้องสมัคร ไม่ส่งขึ้นเซิร์ฟเวอร์
เปิดครั้งแรกต้องมีเน็ต หลังจากนั้นใช้ที่สนามไดรฟ์ได้แม้ไม่มีสัญญาณ

## ความสามารถ
- **บันทึกรอบ:** กรอกสกอร์ พัตต์ 3 พัตต์ ลูกโทษ แฟร์เวย์ GIR จากสกอร์การ์ด (ช่องที่ไม่รู้เว้นว่างได้) · นำเข้าประวัติจาก Golf Live บนเครื่องเดียวกันได้
- **แผนซ้อม:** ประเมินจาก 5 รอบล่าสุดว่าลดสโตรกได้มากสุดตรงไหน (ทีช็อต/ลูกโทษ, เหล็ก, ลูกสั้น, พัตต์) + แบบฝึกพร้อมเป้าหมาย + แบ่งเวลาซ้อม + กลยุทธ์ Bogey Golf
- **ซ้อมไดรฟ์:** กดผลทีละลูก (เต็มหน้าไม้/พอใช้/ตีดิน/ท็อป/หลุดแรง × ซ้าย/ตรง/ขวา + ระยะ) → คะแนนความคงที่ + คำแนะนำตามแบบที่พลาดบ่อย
- **ระยะแต่ละไม้:** ระยะจริง ช่องว่างระยะระหว่างไม้ ตารางเวดจ์ระบบนาฬิกา แนวโน้มความคงที่ต่อเซสชัน
- **จุดตั้งแต่ละไม้:** ภาพตำแหน่งลูก ความกว้างการยืน น้ำหนัก (ถนัดขวา/ซ้าย) ปรับเป็นของตัวเองและจดโน้ตได้
- **เช็คตำแหน่งสดด้วยกล้อง:** ถือมือถือส่องกล้องหลังลงพื้น แอปหาลูกและเท้าสองข้าง → เขียว/เหลือง/แดง ตามตำแหน่งลูกที่ตั้งไว้ของแต่ละไม้ บอกว่าต้องขยับกี่ ซม. และเช็คความกว้างการยืน (ใช้ขนาดลูก 4.27 ซม. เป็นไม้บรรทัด) · ใส่ส่วนสูง → ประมาณความกว้างไหล่ ระดับถือมือถือ และขนาดลูกที่ควรเห็น (กันจับของขาวอื่นผิด) · ปรับเป้าได้บนหน้ากล้องเลย · ตัววัดระดับจากเซนเซอร์เอียง (ขึ้นเขียวเฉพาะตอนถือขนานพื้น ≤ 8°) · มีลูกอื่นในภาพได้ (เลือกลูกที่อยู่หน้าเท้า) · เทียบกับตลับเมตรครั้งเดียวแล้วชดเชยให้ตลอด
- **กล้องวงสวิง:** นับถอยหลัง + อัดวนอัตโนมัติ, สโลว์/ทีละเฟรม, ติดป้ายตำแหน่ง → วัดจังหวะ, หาจังหวะกระทบจากเสียง, วาดเส้น/วงกลม, ติดดาววงต้นแบบ, เทียบ 2 คลิปซิงค์ที่จังหวะกระทบ, นำเข้าคลิปสโลว์โมชันจากกล้องมือถือ
- **จังหวะสวิง:** เสียงนำ 3:1 (เต็มวง) / 2:1 (ลูกสั้น)
- **เส้นลูก (Shot Tracer):** คลิปที่ถ่ายจากด้านหลังผู้ตี → แอปหาลูกที่ตั้ง จังหวะกระทบ ตามลูกที่บินออก แล้วฟิตวิถีลูกตามฟิสิกส์ (แรงต้าน + แรงยกจากสปิน ปรับให้ตรงค่าเฉลี่ยจาก launch monitor) → เส้นแดงเรืองแสงทับคลิปจนลูกตก (คลิปจบก่อนลูกตก: ค้างภาพแล้ววาดต่อ) · ไม่ต้องแตะเลย ทำงานในเครื่อง ไม่ต้องใช้เน็ต · บอกความเร็วลูก ระยะลอย ความสูง มุมออก ทิศออก ซ้าย/ขวา ชื่อรูปทรงลูก (ตรง/เฟด/ดรอว์/สไลซ์/ฮุก/ผลัก/ดึง) เป็นค่าประมาณ · ใช้ระยะของไม้นั้นจากบันทึกซ้อมช่วยคำนวณถ้ามี · บันทึกคลิปใหม่ที่มีเส้นฝังอยู่ (แชร์/ดาวน์โหลด) · ไม่มีเสียงกระทบก็หาจังหวะตีจากภาพเองได้
  - วิธีถ่าย: ปุ่ม "ด้านหลัง" ถือแนวตั้ง ลูกอยู่ส่วนล่าง ~1/4 ของจอ เห็นฟ้าเยอะ ขาตั้งห่างลูก 2–4 ม. · สโลว์โมชันตามลูกได้ไกลกว่า
  - ทดสอบกับคลิปจำลองที่ไม่ได้ใช้ปรับค่า (กล้อง แสง fps ไม้ ต่างกัน มีนก คนเดิน ลูกช่องข้างๆ):
    - ชุดปกติ 300 คลิป: เส้นห่างเส้นจริงเฉลี่ย 0.9% ของความสูงภาพ · 72% ของคลิปอยู่ในระยะ 3% · ช่วงที่เห็นลูกคลาด 1.2%
    - ชุดยาก 400 คลิป (เมฆเคลื่อน ใบไม้ไหว กล้องสั่น วิดีโอเบลอ): เส้นใน 3% 63% (ก่อนปรับ 53%) · เส้นผิด (> 6%) 0.8% (ก่อนปรับ 9.7%) · ถ้าไม่มั่นใจจะไม่วาด
    - ไม่วาดเส้นมั่วตอนตีไม่โดน (0/48) · ชดเชยกล้องสั่นก่อนหาลูก · ตัดจุดรบกวนท้ายเส้นแล้วฟิตใหม่

## ไฟล์
`index.html` (หน้าจอ + สไตล์) · `app.js` (เริ่มแอป ปุ่มย้อนกลับ service worker) · `practice.js` (ทุกหน้า) · `core.js` (คำนวณล้วน) · `vision.js` (หาลูก/เท้าจากภาพกล้อง) · `tracer.js` (เส้นลูก: หาลูก ตามลูก ฟิสิกส์ลูกกอล์ฟ) · `sw.js` (ใช้แบบออฟไลน์)

ทดสอบ: `cd tests && node run.js practice` · เส้นลูก: `node run.js shot-tracer` · วัดผลกับคลิปจำลอง: `node tests/bench-tracer.mjs 300 101`
