# ⛳ Golf Score

แอปจดสกอร์กอล์ฟแบบออฟไลน์ สำหรับก๊วน 1–10 คน (แยกได้หลายก๊วน)

**เปิดแอป:** https://totsapark.github.io/golf-score/

## ติดตั้งบน iPhone
1. เปิดลิงก์ด้านบนด้วย **Safari**
2. กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
3. เปิดแอปจากไอคอนหนึ่งครั้งตอนมีเน็ต หลังจากนั้นใช้แบบออฟไลน์ได้

## ติดตั้งบน Android
เปิดลิงก์ด้วย Chrome → เมนู ⋮ → **ติดตั้งแอป**

## ความสามารถ
- จดตีถึงออน, พัตต์, Tee-off ซ้าย/ตรง/ขวา, GIR, ลูกโทษ (ป่า/น้ำ/OB), บังเกอร์
- Gross / Net พร้อมแต้มต่อ, Handicap โดยประมาณ (WHS) จาก Rating/Slope
- กินตัง: 2 อันดับท้ายต่อหลุม + วงล้อสุ่ม 2 อันดับ, หารค่ากับข้าว
- ส่ง/รับข้อมูลระหว่างก๊วนผ่าน AirDrop หรือ LINE
- โหมดกลางแดด, กันจอดับ
